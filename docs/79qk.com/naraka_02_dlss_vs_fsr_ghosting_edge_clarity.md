# 《永劫无间》超分辨率技术选型：DLSS 与 FSR 远距离草丛敌人重影及边缘模糊消除

**核心排查结论：** 开启 DLSS 或 FSR 后近距离拼刀流畅但远距离观察草丛、树冠处的敌人模型存在明显网格噪点、边缘重影和运动拖尾，核心成因在于游戏内置的旧版 DLSS 动态模型对细小树枝草丛的运动矢量（Motion Vectors）计算置信度不足，通过手动替换游戏根目录下的 nvngx_dlss.dll 为官方最新 3.7+ 运行库，将超采样模式锁定为【质量（Quality）】并将锐化滑块精准调校在 0.55~0.60，可彻底消除远景虚化。

## 二、 核心排查与系统实操调优步骤

### 步骤 1：替换游戏根目录下的 nvngx_dlss.dll 核心库
从官方 TechPowerUp 知识库获取最新验证签名版 nvngx_dlss.dll（推荐 v3.7.0 或以上版本），备份并替换至游戏安装根目录下：

```cmd
文件替换目标路径：
[游戏安装目录]\NarakaBladepoint_Data\Plugins\x86_64\nvngx_dlss.dll
```

### 步骤 2：游戏内配置 DLSS 质量挡位与最佳锐化度
进入游戏设置 -> 画面设置：超分辨率采样选择【NVIDIA DLSS】，模式锁定为【质量 (Quality)】，将锐化度滑块调节至【55% ~ 60%】（过高会导致细线条白边发亮，过低会导致模糊）。

```cmd
关键协同项：
- 动态模糊: 必须彻底关闭 (Off)
- 体积光 / 体积云: 建议设为【极低】或【关闭】
```

### 步骤 3：验证 NVIDIA Profile Inspector 中的预设模型（Preset）
高端玩家可使用开源 NVIDIA Profile Inspector，在《永劫无间》Profile 下将 DLSS 预设强制指定为【Preset E】或【Preset F】，该预设专门针对快速运动和树枝叶片去重影进行了极佳的降噪优化。

```cmd
实战效果测试：在聚窟洲百炼洞或不周滩远眺树木，左右快速摆动视角，确认树叶轮廓无任何拖影模糊。
```

## 三、 常见故障排查与深度 FAQ

#### Q: 替换 nvngx_dlss.dll 会不会被反作弊系统（ACE）封号？
> **A:** 不会。nvngx_dlss.dll 带有 NVIDIA 官方合规数字签名，属于标准显卡图形渲染运行时驱动库，不涉及任何游戏逻辑或内存注入，完全合规安全。

#### Q: GTX 10/16 系列显卡能用 DLSS 吗？
> **A:** DLSS 需要 RTX 显卡内置的 Tensor Core 硬件支持；GTX 系列及 AMD 显卡请在游戏内选择【AMD FSR】或【NIS】空间超采样。
