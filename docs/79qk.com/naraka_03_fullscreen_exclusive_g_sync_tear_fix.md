# 《永劫无间》G-Sync/FreeSync 画面微撕裂与 Windows 全屏优化（FSO）彻底关闭实操

**核心排查结论：** 玩家即使配备了 240Hz/360Hz 顶级电竞显示器且开启了 G-Sync，但在快速划动鼠标索敌时屏幕中下方依然能隐约看到横向断层微撕裂，核心症结在于 Windows 10/11 的“全屏优化（Fullscreen Optimization, FSO）”将全屏独占劫持为 DWM 桌面合成窗口，破坏了显卡与显示器硬件刷新周期的硬同步，通过禁用主程序的全屏优化并在注册表中锁定兼容模式，可激活真正的硬件独占全屏（Exclusive Fullscreen）。

---

## 一、 底层成因排查与参数对比表

| 显示模式 / 状态 | 窗口渲染机制 | G-Sync 硬件同步率 | 输入延迟表现 | 画面撕裂概率 |
| --- | --- | --- | --- | --- |
| 无边框窗口 (Borderless) | DWM 强制介入桌面二次合成 | 仅能部分兼容，偶发掉同步 | 偏高（+6ms ~ 10ms） | 偶发断层撕裂与微抖动 |
| 未优化全屏 (受 FSO 劫持) | 被 Windows 伪装为独占，实则混合分发 | 大部分时间生效，切屏易闪烁 | 中等（+3ms ~ 5ms） | 大招剧烈掉帧瞬间偶发撕裂 |
| 真硬件独占全屏 (FSO 禁用) | 显卡直接控制前置显示缓冲区 | 100% 硬件硬同步锁定 | 极致（< 2ms 驱动直出） | 0 撕裂，纵享丝滑视觉追踪 |

## 二、 核心排查与系统实操调优步骤

### 步骤 1：主程序属性中彻底勾选【禁用全屏优化】
找到游戏安装目录下的主程序 NarakaBladepoint.exe，右键点击选择【属性】->【兼容性】：

```cmd
1. 勾选【禁用全屏优化 (Disable fullscreen optimizations)】
2. 点击【更改高 DPI 设置】-> 勾选【替代高 DPI 缩放行为】，缩放执行选择【应用程序】
3. 点击【确定】并应用保存
```

### 步骤 2：注册表写入 FSO 全局禁用指令
以管理员身份打开 CMD，将主程序加入系统兼容性不降级名单：

```cmd
reg add "HKCU\System\GameConfigStore" /v Win32_FullscreenExclusive /t REG_DWORD /d 1 /f
reg add "HKCU\System\GameConfigStore" /v Win32_DVR_DisableFlags /t REG_DWORD /d 1 /f
```

### 步骤 3：NVIDIA 控制面板配置 G-Sync + V-Sync + 锁帧三角法则
电竞高刷屏消除撕裂的黄金铁三角标准配置：

```cmd
1. 设置 G-SYNC: 勾选【启用 G-SYNC, G-SYNC 兼容】并选择【针对窗口化和全屏模式启用】
2. 管理 3D 设置 -> 垂直同步: 强制【开启 (On)】（负责防撕裂底线保护）
3. 管理 3D 设置 -> 最大帧速率: 设为【刷新率 - 3】（如 240Hz 设 237，确保永远处于 G-Sync 变频区间内部）
4. 游戏内部设置 -> 垂直同步: 彻底【关闭 (Off)】
```

## 三、 常见故障排查与深度 FAQ

#### Q: 为什么开了 G-Sync 还要在显卡驱动里开垂直同步？
> **A:** 这是 NVIDIA 官方白皮书标准规范：当帧率低于刷新率时，由 G-Sync 动态同步；驱动层的垂直同步仅作为后备保护，防止偶发帧率冲破刷新率上限瞬间导致 G-Sync 失效产生顶部撕裂；而由于锁帧（-3 FPS），垂直同步永远不会真正触发输入延迟。

#### Q: 怎么确认当前游戏是否已经进入硬件独占全屏？
> **A:** 在游戏中按键盘音量调节键（Fn+音量加减），如果屏幕左上方不弹出 Windows 原生音量浮条，证明游戏已完全接管硬件独占全屏。
