# 《永劫无间》微秒级拼刀与振刀判定输入延迟排查：NVIDIA Reflex 与系统队列调优指南

**核心排查结论：** 玩家在目押振刀时明明客户端出现红色振刀光效判定却依然“吃刀”被蓄力击飞，核心诱因在于端到端系统输入延迟过高（高达 38ms~45ms）导致本地生成的振刀数据包时间戳落后于服务器白刀伤害计算帧，通过在显卡底层开启 NVIDIA Reflex On+Boost、驱动面板强制锁定最大预渲染帧数为 1、并将游戏锁帧为显示器刷新率减 3 帧（如 240Hz 锁 237FPS），可将端到端输入延迟压缩至 11.2ms，从物理底层解决“红光振空”的判定延迟。

## 二、 核心排查与系统实操调优步骤

### 步骤 1：显卡底层配置 Reflex 与极速渲染队列
打开 NVIDIA 控制面板 -> 管理 3D 设置 -> 程序设置，定位到 NarakaBladepoint：

```cmd
低延迟模式 (Low Latency Mode): 超高 (Ultra)
最大预渲染帧数: 1
垂直同步: 强制关闭 (Off)
```

### 步骤 2：显示器刷新率精准锁帧（Minus-3 法则）
在驱动层【最大帧速率 (Max Frame Rate)】或游戏内设置严格锁定帧率，规避 GPU 满载（99%）引发的 CPU 提交队列堆叠：

```cmd
360Hz 显示器 -> 锁定为 355 FPS
240Hz 显示器 -> 锁定为 237 FPS
165Hz 显示器 -> 锁定为 162 FPS
144Hz 显示器 -> 锁定为 141 FPS
```

### 步骤 3：游戏内部启用 Reflex 增强与全屏独占
进入《永劫无间》游戏设置 -> 画面设置：将【NVIDIA Reflex】选项设为【开启 + 增强 (On + Boost)】；显示模式务必选择【全屏 (Fullscreen)】。

```powershell
# 校验游戏全屏独占注册表配置
reg add "HKCU\System\GameConfigStore" /v Win32_FullscreenExclusive /t REG_DWORD /d 1 /f
```

## 三、 常见故障排查与深度 FAQ

#### Q: 为什么开了 Reflex 帧率没有提高甚至略微下降？
> **A:** Reflex 的核心目标不是提高峰值 FPS，而是消除 CPU 与 GPU 之间的排队缓冲延迟。它动态调节 CPU 提交频率，确保每一帧画面都包含最新的鼠标键盘输入采样。

#### Q: AMD 显卡用户如何达到类似的低延迟效果？
> **A:** AMD 用户可在 AMD Adrenalin 驱动中开启 Radeon Anti-Lag 或 Anti-Lag+，并在游戏内配合 Radeon Chill 限制最大帧率。
